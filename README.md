# Telegram Mini App — USDT-кошелёк, рынки, переводы, админка

Что внутри:
- Telegram-бот (Telegraf) — открывает мини-апп, уведомления
- Backend (Express) — API профиля, переводов, поддержки, рынков, админки
- PostgreSQL (Prisma) — пользователи, балансы USDT, номера счетов, тикеты
- Мини-апп в тёмном стиле (Bybit-like) — рынки, кошелёк, переводы, новости
- Веб-админка `/admin.html` — баланс, номера счетов, ответы в поддержку

Баланс — внутренний USDT. Пополнения за реальные деньги нет: админ
начисляет USDT вручную, пользователи переводят между собой по номеру счёта.

## 1. Подготовка

1. Бот через [@BotFather](https://t.me/BotFather) → `BOT_TOKEN`
2. Menu Button → URL после деплоя (`WEBAPP_URL`)
3. Группа админов → добавить бота → узнать `ADMIN_CHAT_ID` через `getUpdates`
4. Придумать `ADMIN_SECRET` для входа в `/admin.html`

## 2. Локальный запуск

```bash
npm install
cp .env.example .env
npx prisma migrate deploy
npm run dev
```

Админка: `http://localhost:3000/admin.html` (секрет из `.env`).

## 3. Railway

1. Deploy from GitHub + PostgreSQL
2. Variables: `BOT_TOKEN`, `ADMIN_CHAT_ID`, `ADMIN_SECRET`, `NODE_ENV=production`,
   `WEBAPP_URL`, `WEBHOOK_URL` (оба — публичный домен сервиса)
3. `npx prisma migrate deploy`
4. BotFather → Menu Button = `WEBAPP_URL`

## 4. Как работает номер счёта

1. Пользователь в кошельке нажимает **Получить номер счёта**
2. Статус → `pending`, уведомление в `ADMIN_CHAT_ID`
3. Админ в `/admin.html` → «Заявки на счёт» указывает номер и сохраняет
4. Пользователь видит номер и может принимать/отправлять переводы

Перевод возможен по номеру счёта или по Telegram username (если у получателя уже есть счёт).

## 5. Админка

- Пользователи: поиск, правка баланса USDT, номера счёта, верификации
- Заявки на счёт: очередь `pending`
- Поддержка: список открытых тикетов, ответ (дублируется в Telegram пользователю), закрытие

## 6. Депозит и KYC

**Депозит:** админ в карточке пользователя задаёт адреса (USDT TRC20/ERC20, BTC).
Пользователь в приложении: Активы → Депозит → выбирает валюту и сеть → видит свой адрес и QR.
Зачисление на баланс USDT делает админ вручную после проверки поступления.

**KYC:** Профиль → Верификация → ФИО, страна, фото документа и селфи.
Админ: раздел KYC → открыть → одобрить / отклонить.
